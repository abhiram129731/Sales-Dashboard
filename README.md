# Sales Analysis Dashboard — Power BI

## Overview
An interactive sales analytics dashboard built using Microsoft Power BI to explore sales performance, profitability, product performance, and sales distribution.

## Dashboard Features
- **KPI cards:** Total sales, profit, quantity, and profit percentage
- **Monthly analysis:** Sales and profit trends across months
- **Product analysis:** Comparison of sales by product
- **Payment analysis:** Online versus cash payment distribution
- **Daily analysis:** Day-wise sales trends
- **Sales segmentation:** Breakdown by sales type
- **Interactive filters:** Year, month, payment mode, and sale type

## Tools Used
- Microsoft Power BI Desktop
- Power Query / data transformation,
- DAX measures,


## Key Business Questions
1. How do sales and profits change over time?
2. Which products contribute the most to sales?
3. How are sales distributed across payment modes?
4. Which sales types contribute the most to revenue?
5. What patterns can help inform business decisions?

## How to View
1. Download the `.pbix` file from this repository.
2. Open it using Power BI Desktop.
3. Refresh the data if the original data source is available.
4. Explore the report using its interactive filters.
